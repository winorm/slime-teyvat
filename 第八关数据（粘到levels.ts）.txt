《第八关 · 可疑人员》数据 —— 直接粘到 levels.ts
================================================
一共三块：
  【A】levels.ts 的类型/配色补充（加一次就够，以后新关不用再加）
  【B】第八关那条关卡数据（粘到 LEVELS 数组最后，第七关后面）
  【C】粘完要检查的几件事

（这份文件只是给你复制用的，粘完可以删。）


【A】levels.ts 里的类型与配色补充
------------------------------------------------

① BgTheme 加一个 'harbor'：

export type BgTheme = 'beach' | 'field' | 'church' | 'sky' | 'tower' | 'liyue' | 'harbor'


② THEME_COLORS 里加一行（放在 liyue 后面）：

  // 璃月·港口：白天的石岸与木栈桥，危险的蓝偏亮一点（水色）
  harbor: { ground: 0x8a6a4a, oneWay: 0xb09068, crumble: 0x9a5a44, hazard: 0x2f6f8f },


③ 类型（放在 MonsterDef 后面）：

// 千岩军：巡逻 + 扇形视野（视野朝斜下方）。看见玩家 2.5 秒转追击，追击撞到障碍就放弃
export type GuardDef = {
  x: number
  y: number        // 底边贴地那条线
  range: number    // 以 x 为中心左右各巡逻多远
  speed?: number   // 巡逻速度，默认 26
  facing?: 1 | -1  // 开局朝向，默认朝右
  vision?: number  // 视野半径，默认 170
}

// 画在玩家前面的摆件：牌楼前层、停在水里的船、前景灯笼之类
export type ForegroundDef = {
  x: number
  y: number        // 底边那条线
  key: string
  scale?: number
  alpha?: number
}


④ LevelDef 里加这几个问号字段（放在 `hints: HintDef[]` 后面）：

  guards?: GuardDef[]
  foreground?: ForegroundDef[]
  chaseAt?: number          // 走过这条线：演出一下、立刻生成追击小队
  squadCount?: number       // 小队人数，默认 3
  squadSpeed?: number       // 追击速度，默认 92（玩家全速 100）
  squadSpawnGap?: number    // 生成在玩家身后多少像素，默认 260
  squadStop?: number        // 跑过这条线就甩掉他们
  chaseCause?: string       // 被抓时的死因，默认 'guard'（死亡界面会写"被千岩军抓住了……"）

  说明：其实这几条我已经按"同名可选字段"读了，不加也能跑；加进类型是为了你写数据时有提示、typo 也能被 tsc 抓到。

【C】粘完检查这几件事
------------------------------------------------

1. 打开 `npm run build` —— 类型没错就说明 A 的字段加对了。
2. 进第八关（选关界面会多出"第八关"，或者地址带 `?fresh=1` 之后换关）走一遍：
   码头 → 集市街 → 爬石阶（中途用岩柱压板开铁栅栏）→ 广场躲两名千岩军 →
   （后面是逃脱）跑过 x=4400 触发追击 → 跑到 5480 甩掉 → 最右边开箱。
3. 三个原石的位置：矮通道里那颗要"跳起来往右挤"才拿得到；另两颗在逃脱的屋顶和终点码头上。
4. 觉得哪一段太挤/太空，告诉我段号（①~⑤）+ 想加什么，我改坐标；新美术（房子/牌楼/灯笼/摊位/人群/船）
   使用之前都在测试关「港口」厅里过过目了。

（另外：`?dev=1` 的测试关入口、港口厅这些都不影响正式关卡；`DEV_MODE` 打包前记得改回 false。）
